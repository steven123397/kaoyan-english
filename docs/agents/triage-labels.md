# Triage Labels

| Label in skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 尚未安排 |
| `needs-info` | `needs-info` | 等待学习者补充信息或提交练习 |
| `ready-for-agent` | `ready-for-agent` | 信息充分，可由 Codex 继续处理 |
| `ready-for-human` | `ready-for-human` | 等待学习者亲自完成写作或练习 |
| `wontfix` | `wontfix` | 不再执行 |

当技能提到某种 triage 角色时，使用表中对应的 GitHub 标签。后续可按实际
工作流修改右侧标签名称。
