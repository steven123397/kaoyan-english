# 考研英语考试要求与题型资料库

本目录用于维护全国硕士研究生招生考试英语（一）和英语（二）写作部分的当前要求、题型范围及历年变化。

## 文件

- [考研英语作文题型与考试要求.md](./考研英语作文题型与考试要求.md)：当前有效的完整总结。备考规划应优先读取此文件。
- [真题来源与归档建议.md](./真题来源与归档建议.md)：比较在线题库、可编辑题面和完整原卷来源，并给出本地归档策略。
- [变化记录.md](./变化记录.md)：按考试年度记录大纲、管理规定和题型口径的变化及核验状态。

原有的 `作文/英一英二写作题型调研.md` 保留为早期调研稿，不作为后续更新入口。

## 来源优先级

1. 教育部、教育部教育考试院、中国教育考试网和中国研究生招生信息网发布的文件或页面。
2. 教育部教育考试院编写、官方出版社出版的当年考试大纲和考试分析。
3. 官方公布的样题、题型示例及其他可直接核验材料。
4. 高校出版社、招生单位等可追溯材料，仅用于补充说明。
5. 培训机构和考试资讯网站只能用于发现线索，不得单独支撑“官方要求发生变化”的结论。

## 更新规则

- 每年新大纲或招生工作管理规定发布后核对一次。
- 区分“大纲允许的范围”“历年实际命题规律”和“备考策略”，不得混写。
- 每个变化必须注明考试年度、发布日期、来源链接和核验结论。
- 官方正文无法免费取得时，应明确标为“待正版大纲核验”，不得用转载内容冒充一手来源。
- 主报告只保留当前有效结论；被替代的结论移入变化记录。
